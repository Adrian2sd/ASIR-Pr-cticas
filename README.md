# ASIR · Prácticas y proyectos

Portfolio técnico de prácticas realizadas durante **2.º de Administración de Sistemas Informáticos en Red (ASIR)**.

Este repositorio recopila laboratorios y proyectos desarrollados durante mi formación, documentados con un enfoque profesional para mostrar de forma clara el entorno utilizado, la implementación realizada, las pruebas de funcionamiento y los conocimientos técnicos trabajados.

> Las prácticas proceden de un entorno académico y han sido reorganizadas y documentadas como memorias técnicas de mi trabajo realizado.

---

## Sobre el repositorio

El objetivo de `asir-practicas` es reunir en un único repositorio una selección de trabajos realizados durante el curso y convertirlos en documentación que permita entender rápidamente:

- qué se pretendía conseguir;
- qué entorno de laboratorio utilicé;
- qué tecnologías intervienen;
- qué configuración realicé;
- cómo comprobé su funcionamiento;
- qué conocimientos técnicos demuestra cada práctica.

La estructura principal sigue las **asignaturas técnicas de 2.º ASIR**, en lugar de utilizar categorías genéricas.

## 01 · Administración de sistemas gestores de bases de datos

Prácticas relacionadas con la instalación, configuración, administración y utilización de distintos sistemas gestores de bases de datos.

Entre los trabajos documentados se encuentran:

- instalación y configuración de **MySQL**;
- configuración de red, memoria y logs de MySQL;
- despliegue de **MySQL, MariaDB y PostgreSQL en Ubuntu**;
- operaciones con **MongoDB** desde `mongosh`;
- acceso a MongoDB desde **Node.js**;
- utilización de **MariaDB con Python, SQLAlchemy y PyMySQL**;
- análisis del SQL generado por un ORM;
- gestión de usuarios y privilegios de base de datos.

---

## 02 · Administración de sistemas operativos

Laboratorios centrados en administración, virtualización, procesos y servicios de sistemas Windows y Linux.

Algunos de los trabajos realizados incluyen:

- instalación de **Proxmox VE en VirtualBox**;
- creación y administración de **contenedores LXC**;
- utilización de **snapshots** y restauración de estados;
- administración de procesos en **Windows y Ubuntu**;
- uso de `tasklist`, `taskkill`, PowerShell, `ps`, `pstree`, `top` y otras herramientas;
- diagnóstico y optimización del rendimiento;
- gestión de recursos de máquinas virtuales;
- laboratorios con **Windows Server y Active Directory Domain Services**.

## 05 · Servicios de red e Internet

Prácticas orientadas a la configuración y comprobación de servicios de infraestructura y comunicaciones.

Entre los laboratorios realizados se encuentran:

- configuración de **DHCP**;
- configuración y validación de **DNS**;
- despliegues en **Windows Server y Ubuntu**;
- simulaciones de red con **Cisco Packet Tracer**;
- configuración de servicios **FTP**;

- comprobaciones de conectividad y funcionamiento de servicios.

## Cómo está documentada cada práctica

La estructura se adapta al contenido real de cada proyecto, evitando añadir archivos o carpetas innecesarias.

Cuando corresponde, la documentación incluye:

- objetivo del laboratorio;
- entorno utilizado;
- arquitectura o diseño;
- implementación;
- comandos y configuraciones;
- pruebas realizadas;
- capturas como evidencia;
- problemas encontrados y soluciones reales;
- resultado;
- conocimientos trabajados;
- posibles mejoras.

Las capturas se conservan como evidencia del trabajo realizado y se sitúan junto a la explicación técnica correspondiente.

---

## Criterio de documentación

Este repositorio pretende reflejar el trabajo de forma transparente.

Por ello:

- no se presentan como propias instrucciones proporcionadas por profesores;
- las instrucciones se transforman, cuando aportan valor, en contexto técnico;
- las acciones respaldadas por mis evidencias se explican como trabajo realizado;
- no se inventan configuraciones, resultados o incidencias;
- las posibles mejoras se diferencian de lo que ya está implementado.

---


## Objetivo profesional

Este portfolio está orientado a mostrar de forma práctica los conocimientos adquiridos durante ASIR y complementar mi formación académica con evidencias reales de configuración y administración de sistemas.

Mi objetivo es poder demostrar no solo las tecnologías que he estudiado, sino también **cómo las he utilizado, configurado y comprobado en entornos de laboratorio**.
